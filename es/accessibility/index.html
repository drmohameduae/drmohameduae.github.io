Accesibilidad

Una declaración de accesibilidad honesta: el objetivo WCAG 2.2 nivel AA, lo que este sitio admite, las limitaciones conocidas y cómo contactarnos.

Declaración de accesibilidad

La accesibilidad es un requisito de publicación y una medida de respeto en esta plataforma, no una mejora opcional.

DRMOHAMED.NET tiene como objetivo las Pautas de Accesibilidad al Contenido Web (WCAG) 2.2 en el nivel AA, en línea con la orientación nacional de accesibilidad digital de los EAU. Esta declaración describe el objetivo, las características que este sitio está construido para admitir, las limitaciones que conocemos y la vía para comentarios.

Lo que este sitio está construido para admitir

  • Uso del teclado para cada tarea esencial, con enlace de salto, foco visible y movimiento de foco predecible.
  • Lectores de pantalla, mediante una secuencia lógica de encabezados, puntos de referencia significativos y controles etiquetados programáticamente.
  • Zoom hasta el 400 por ciento con redistribución, de modo que el contenido no requiera desplazamiento bidimensional salvo en tablas de datos reales.
  • Ajustes de movimiento reducido, sin audio automático, sin límites de tiempo y sin contenido parpadeante.
  • Subtítulos o transcripciones para los medios temporales.
  • Lenguaje sencillo, un título de página visible por página y mensajes de error explicados en texto.

Limitaciones conocidas

Esta declaración no afirma conformidad plena mientras quede alguna barrera sin resolver. Los análisis automatizados son útiles pero no suficientes por sí solos, por lo que la revisión de accesibilidad de esta plataforma combina comprobaciones de contenido, diseño y código con pruebas manuales de tareas.

La evidencia de las pruebas manuales de la versión 1.0 se compila en el lanzamiento, y esta declaración se actualiza para reflejar la última revisión. Cuando una barrera conocida no pueda corregirse de inmediato, se nombrará aquí junto con la corrección prevista, en lugar de ocultarse con un lenguaje absoluto.

Comentarios

Si algo en este sitio web resulta difícil de usar, díganoslo a través del formulario de contacto. Nombre la página y describa el problema con las palabras que le resulten naturales. Los comentarios de accesibilidad entran en el mismo flujo de corrección que cualquier corrección editorial, y los informes y tiempos de respuesta se registran para que la vía siga siendo honesta.

Formatos alternativos

Si necesita algún contenido en un formato alternativo, solicítelo a través del formulario de contacto. La plataforma proporcionará una alternativa razonable cuando sea posible y le dirá con claridad si una solicitud concreta no puede atenderse.

Revisión de esta declaración

Esta declaración se emitió el 26 de julio de 2026. Se revisa en cada lanzamiento, cuando el sitio cambia sustancialmente y en un ciclo programado, y la evidencia de accesibilidad que la respalda se conserva con el registro del lanzamiento. Las páginas legales y de confianza se prueban con el mismo nivel que las páginas editoriales.

Estado de este aviso

Esta página es la versión base 1.0 emitida el 26 de julio de 2026. La redacción final está sujeta a la aprobación de asesor jurídico cualificado en los EAU antes del lanzamiento público, y se actualizará si cambia la configuración de producción o si las pruebas de accesibilidad identifican nuevas barreras.
